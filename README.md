# Shell Emulator

Эмулятор командной оболочки UNIX-подобной операционной системы.

Вариант №8.

## Этап 1. REPL

На первом этапе реализован графический прототип эмулятора.

Поддерживается:

- графический интерфейс на Java Swing;
- заголовок окна с реальными именем пользователя и hostname;
- ввод команд в интерактивном режиме;
- раскрытие переменных окружения, например `$HOME`;
- разбор строки на команду и аргументы;
- команды-заглушки `ls` и `cd`;
- команда `exit`;
- сообщения об ошибках для неизвестных команд и неверных аргументов.

## Требования

- JDK 21;
- Gradle.
